## Usage & Reproduction Notes

- All prompts enforced strict **originality and code independence** rules: the reference application was treated strictly as a visual/behavioral target; no reference source code, React components, CSS, or JS bundles were downloaded, decompiled, or copied.
- Viewports across all steps were standardized on desktop (`1440 × 900` at 100% zoom).
